# Code of Conduct

## Our standard

Participants must communicate respectfully, critique work rather than people,
welcome good-faith questions, and avoid harassment, threats, discrimination,
doxxing or disclosure of confidential material. Technical disagreement is
expected; personal hostility is not.

## Scope and enforcement

This standard applies to repository discussions, issues, pull requests and
other ReviewGraphen project spaces. Maintainers may edit or remove abusive
content and may temporarily or permanently restrict participation when needed
to protect contributors and the project.

Report conduct concerns privately to the repository owner through the
CAPHTECH GitHub organization. Do not use a public issue when doing so would
expose a target or confidential details. Maintainers will disclose conflicts of
interest and hand the report to another organization owner when possible.
